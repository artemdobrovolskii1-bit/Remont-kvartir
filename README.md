# РемКвартал — демо-сайты для компании по ремонту квартир

Пять шаблонов сайта. Данные (адрес, телефон, отзывы) — образец. Откройте index.html — страница с тарифами.

- `1-start/` — Старт: сайт-визитка
- `2-vitrina/` — Витрина: лендинг с проектами и ценами, слайдер «до и после»
- `3-magazin/` — Магазин: каталог 50 проектов ремонта, фильтры, «Моя смета», калькулятор
- `4-premium/` — Премиум: конфигуратор проекта, онлайн-бронь замера, районы, рассрочка 0%
- `5-premium-plus/` — Премиум+: 3D-модель квартиры (ремонт при прокрутке), 3D-конфигуратор со сметой в PDF, планировка, график ремонта, личный кабинет, запись на встречу

В папке 5-premium-plus файл three.min.js (библиотека 3D-графики Three.js, лицензия MIT) должен лежать рядом с index.html.
